# Resonate development

This repository contains only the Resonate call-analysis demo. Territory planning is maintained separately in EliottLS/Website_Creation_w_ChatGPT_Codex; do not copy it into this repository.

Use Node 24 and npm ci. Start with npm run dev. Validate with npm run build and npm test. Browser tests use Playwright Chromium; locally, CHROMIUM_PATH=/usr/bin/chromium npm test can use system Chromium. CI installs the pinned Playwright browser.

All sample calls and performance metrics are fictional. Keep demo labels accurate. Do not claim live AI, transcription, email sending, CRM updates, or calendar invitations without implementing and verifying those integrations. Never commit credentials.
